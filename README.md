\# 🎟️ Ticket Vending GUI (Qt)



A desktop-based ticket vending system built using \*\*Qt (C++ \& QML)\*\* that simulates a real-world ticket vending machine.



\---



\## 🚀 Features



\* 🎫 Ticket selection interface

\* 🖥️ GUI built with Qt Quick (QML)

\* ⚙️ Backend logic in C++

\* 🔄 UI ↔ Backend interaction

\* 📊 Real-time updates



\---



\## 🛠️ Tech Stack



\* C++

\* Qt 6 (QML)

\* CMake

\* Qt Creator
